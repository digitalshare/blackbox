# Dead Reckoning

Dead Reckoning is a 3D sci-fi mystery powered by a Bruin data pipeline. When a storm-hit ship’s reactor sensors disagree, the AI crew follows the data to find out who’s been tampering with the readings. Rescue is eight ticks away.
